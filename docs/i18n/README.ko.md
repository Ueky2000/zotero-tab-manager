## Tab Manager 소개

논문을 수십 편씩 열어 놓으면 탭이 빽빽해지고 제목이 잘려 원하는 문헌을 찾기 어렵습니다. 왜 열었는지 잊기도 합니다. Tab Manager는 연구 주제에 따라 문헌 탭을 정리합니다.

| 기능 | 설명 |
| --- | --- |
| 🗂️ 주제별 그룹 | 같은 연구 과제, 방법론, 읽기 작업의 문헌을 모으고, 작업을 마치면 그룹의 탭을 한 번에 닫습니다. |
| 🎨 색상과 접기 | 그룹별 색상을 지정하고 당장 읽지 않는 그룹을 접습니다. 미분류 탭에도 적용됩니다. |
| ✍️ 나만의 메모 | “실험 자세히 보기”, “코드 있음”처럼 탭에 메모를 붙입니다. 원래 제목, 메모, 둘 다 중에서 선택하고 그룹별로 통일할 수 있습니다. |
| 🔎 열린 문헌 검색 | 메모, 파일명, 원래 제목으로 검색하고 접힌 그룹 안의 문헌으로도 이동합니다. |
| 🕒 닫기 제안 | 오래 다시 보지 않은 문헌과 경과 일수를 확인합니다. 닫을지는 사용자가 결정합니다. |
| 💾 읽기 상태 복원 | 그룹, 색상, 순서, 메모, 접힌 상태를 저장하여 재시작 후에도 이어서 사용합니다. |

그룹 이름과 문헌 탭은 같은 줄에 표시됩니다. 탭을 닫아도 문헌이나 첨부 파일은 삭제되지 않습니다.

## 설치

1. [최신 릴리스](https://github.com/Ueky2000/zotero-tab-manager/releases/latest)에서 **`.xpi`** 파일을 다운로드합니다.
2. Zotero에서 **도구 → 플러그인 → 톱니바퀴 → 파일에서 부가 기능 설치**로 파일을 선택합니다. 일부 버전에서는 메뉴 이름이 “부가 기능”입니다.
3. 문헌을 열고 탭 표시줄의 **+**로 그룹을 만든 다음, 탭을 그룹 이름으로 끌어 놓습니다.

기존 버전 위에 설치해도 설정이 유지됩니다. 필요한 경우 Zotero를 다시 시작하세요.

## 사용법

- **그룹:** 탭을 그룹 이름에 끌어 놓거나 탭의 오른쪽 클릭 메뉴에서 추가합니다. 그룹 이름을 클릭하면 접거나 펼치고, 끌면 그룹 순서가 바뀝니다.
- **끌어 놓기:** 그룹에 넣는 위치와 문헌 앞뒤에 삽입하는 위치를 구분해 표시합니다. 접힌 그룹 위에서 약 600ms 기다리면 잠시 펼쳐지며, 드래그를 취소하면 원래 상태로 돌아갑니다.
- **색상:** 그룹의 오른쪽 클릭 메뉴에서 기본 색상을 선택하거나 16진수 색상 값을 입력합니다. 미분류 그룹도 지원합니다.
- **메모:** 문헌 탭을 오른쪽 클릭해 설정합니다. 그룹 메뉴에서 기존 탭과 새로 들어오는 탭의 표시 방식을 함께 지정할 수 있습니다.
- **검색:** 오른쪽 검색 버튼을 사용합니다. 결과를 선택하면 해당 그룹을 펼치고 문헌으로 전환합니다.
- **닫기 제안:** 맨 오른쪽 버튼에서 확인합니다. 기본 기준은 7일이며 변경할 수 있습니다. 자동으로 닫지 않습니다. 조회 간격은 플러그인이 기록을 시작한 시점부터 계산합니다.
- **그룹 탭 닫기:** 그룹 메뉴에서 모든 읽기 탭을 닫되 그룹 소속 정보는 유지합니다. 그룹 해제는 그룹 분류를 없애는 별도 작업입니다.

그룹 메뉴 순서: 이름 변경, 그룹 해제, 그룹 색상, 탭 표시, 그룹의 모든 문헌 닫기.

v0.5.1에서는 탭이 많을 때 오른쪽 도구가 창 밖으로 밀려나는 문제를 수정했습니다. 마우스 휠로 가로 스크롤할 수 있으며, 화면 밖의 탭을 활성화하면 해당 탭이 자동으로 보입니다.

## 호환성

하나의 XPI가 **Zotero 6.0–10.0.x**를 대상으로 합니다. 2026-11-17 Windows의 독립 프로필에서 6.0.36은 설치 및 핵심 기능 34개 항목, 7.0.32·8.0.4·9.0.6·10.0.8은 각각 38개 항목을 통과했습니다. 7.0.32에서는 회귀 검사 130개도 통과했습니다. macOS, Linux 및 다른 패치 버전은 실제 설치 환경에서 검증하지 않았습니다. [검증 기록](../COMPATIBILITY.md)을 참고하세요.

## 데이터와 업데이트

설정은 라이브러리 ID와 첨부 파일 key를 기준으로 로컬 Zotero 프로필에 저장되며 라이브러리와 동기화되지 않습니다. 파일명, 문헌 제목, Zotero 노트를 변경하지 않습니다. 플러그인을 비활성화하면 기본 탭 표시줄로 돌아가고 설정은 보존됩니다.

플러그인 ID `tab-groups@local.zotero`와 설정 키 `extensions.tabGroups.state`를 유지하여 기존 설정과 조회 기록을 이어받습니다. 일반 기능은 문헌 정보를 업로드하지 않습니다. Zotero 자체는 부가 기능 업데이트 설정에 따라 이 저장소의 업데이트 정보와 설치 파일에 접근할 수 있습니다.
