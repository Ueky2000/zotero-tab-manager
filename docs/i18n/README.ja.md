## Tab Manager について

論文を何十本も同時に開くと、タブが混み合い、タイトルが見切れ、目的の論文を見失いがちです。なぜ開いたのか忘れてしまうこともあります。Tab Manager は、研究のテーマに沿ってタブを整理します。

| 機能 | できること |
| --- | --- |
| 🗂️ テーマ別のグループ | 同じ課題、手法、読書タスクの文献をまとめ、作業終了後にグループ内のタブを一括で閉じられます。 |
| 🎨 色と折りたたみ | グループの色を自由に設定し、今は使わないグループを折りたためます。未分類のタブにも対応します。 |
| ✍️ タブのメモ | 「実験を重点的に読む」「コードあり」などのメモを付けられます。元のタイトル、メモ、両方から表示を選び、グループ単位で統一できます。 |
| 🔎 開いている文献の検索 | メモ、ファイル名、元のタイトルから検索できます。折りたたんだグループ内の文献にも移動できます。 |
| 🕒 閉じる候補 | 長く再閲覧していない文献と経過日数を表示します。閉じるかどうかは自分で決められます。 |
| 💾 読書状態の保存 | グループ、色、順序、メモ、折りたたみ状態を再起動後も保持します。 |

グループ名と文献タブは同じ行に表示されます。タブを閉じても、ライブラリの文献や添付ファイルは削除されません。

**v1.0.0** 以降は **Zotero 7–10** に対応します。

## インストール

1. [最新リリース](https://github.com/Ueky2000/zotero-tab-manager/releases/latest)から **`.xpi`** をダウンロードします。
2. Zotero の **ツール → プラグイン → 歯車 → ファイルからアドオンをインストール** で選択します。バージョンによっては「アドオン」と表示されます。
3. 文献を開き、タブバーの **+** でグループを作成し、タブをグループ名へドラッグします。

旧版に上書きインストールできます。必要に応じて Zotero を再起動してください。

## 使い方

- **グループ：** タブをグループ名へドラッグするか、タブの右クリックメニューから追加します。グループ名をクリックすると折りたたみ／展開、ドラッグすると並べ替えができます。
- **ドラッグ：** グループへの追加と、文献の前後への挿入を位置表示で区別します。
- **色：** グループを右クリックし、プリセットまたは 16 進数で指定します。未分類にも設定できます。
- **メモ：** 文献タブを右クリックして設定します。グループの右クリックメニューから、既存および今後追加するタブの表示方法を統一できます。
- **検索：** 右側の検索から文献を探します。結果を選ぶと、グループを展開して文献に切り替えます。
- **閉じる候補：** 右端のボタンから確認できます。初期値は 7 日間で変更可能です。自動では閉じません。閲覧間隔はプラグインが記録を開始した時点から計算します。
- **一括で閉じる：** グループの右クリックメニューから実行します。所属情報は保持されます。

## 互換性

**v1.0.0 以降は Zotero 7.0–10.0.x に対応します。**

> **Zotero 6 をお使いの場合は [0.6.6](https://github.com/Ueky2000/zotero-tab-manager/releases/tag/v0.6.6) をダウンロードしてください。** 保守コストを抑えるため、Zotero 6 向けの更新・保守は終了しました。

v1.0.0 の XPI を、Windows の独立したプロファイルで Zotero 7.0.32、8.0.4、9.0.6、10.0.8 について確認しています。macOS、Linux、その他のパッチバージョンは実機未検証です。詳細な結果と範囲は[検証記録](../COMPATIBILITY.md)をご覧ください。

## データと更新

設定はライブラリ ID と添付ファイル key を使ってローカルの Zotero プロファイルに保存され、ライブラリとは同期しません。ファイル名、文献タイトル、Zotero ノートは変更しません。無効にすると標準のタブバーに戻り、設定は保持されます。

プラグイン ID `tab-groups@local.zotero` と設定キー `extensions.tabGroups.state` を維持し、既存の設定と閲覧記録を引き継ぎます。通常機能で文献情報を送信することはありません。Zotero 自体は更新設定に従い、このリポジトリの更新情報とインストールパッケージへアクセスする場合があります。
