# 设置与阅读现场

Zotero 7–10：打开 Zotero 的设置，在左侧选择 **Tab Manager**。

Zotero 6：从「工具 → 插件」中找到 **Tab Manager**，点击其「选项 / 首选项」打开兼容设置窗口。

修改设置后立即生效，无需重启。

标签栏的“搜索文献”和“建议关闭”按钮均为切换按钮：首次点击打开，再次点击关闭；切换到另一个按钮时关闭原来的弹窗。

## 可调整的选项

| 选项 | 作用 |
| --- | --- |
| 重新打开文献时自动进入上一次的分组 | 默认开启。关闭文献后记住它所属的分组；下次打开时自动归组，原组已不存在则重建。关闭此选项后，之后关闭并重新打开的文献进入未分组，不移动当前打开的文献。 |
| 关闭组内所有文献后自动解散分组 | 默认关闭。开启后，使用分组右键的一键关闭操作会同时移除已空的自建分组；未分组始终保留。单独关闭标签不触发。其他窗口还有组内文献，或部分标签未关闭时，也保留分组。 |
| 是否允许未分组重命名 | 默认关闭。开启后，未分组的右键菜单显示“重命名此分组”，自定义名称在重启后保留。关闭开关时，隐藏重命名入口并立即恢复“未分组”；重启或恢复旧阅读现场也不会带回自定义名称。文献归属保持不变。 |
| 显示文献数量 | 控制组名后是否显示数量，不改变组名宽度。 |
| 分组内文献超过此数量时竖向排列 | 默认 7，可设为 1–1000。每组打开的文献超过该数量时，点击组名在下方弹出竖向列表；未分组同样适用。 |
| 分组数量超过此值时全部竖向排列 | 默认 7，可设为 1–1000。自建分组数超过此值时，所有分组（包括未分组）使用竖向列表；不计未分组本身。减少分组或调高阈值后恢复按各组文献数量判断。 |
| 默认标签显示 | 选择原文件名、备注或同时显示；修改后立即统一当前所有分组和已打开文献的显示方式。之后仍可单独调整分组或文献。没有备注时显示原文件名。 |
| 显示建议关闭按钮 | 控制标签栏最右侧的“建议关闭”按钮。 |
| 建议关闭天数 | 1–3650 天，默认 7 天；不会自动关闭文献。 |

自动恢复分组使用文献库 ID 和附件 key 匹配，不修改文件名或文献本身。原组已不存在时优先复用同名分组，避免重复创建。主动将文献移出分组会清除它旧的分组记忆。

自动解散不删除文献、备注或手动保存的阅读现场。若开启重新打开时恢复分组，再次打开刚关闭的文献时会重建原组。未分组的颜色可在其组名的右键菜单中调整，设置页不再重复提供颜色控件。

设置页最底部用分隔线单独显示当前运行的插件版本、[项目网站](https://github.com/Ueky2000/zotero-tab-manager)，以及反馈入口：可在[小红书帖子](https://xhslink.cn/o/5yD58jP6BNV)下留言，或发送邮件至 [ueky@foxmail.com](mailto:ueky@foxmail.com)。

将正在阅读的文献移动到另一组后，会展开目标组，并将该文献标签滚动到可见区域。

竖向列表按组内顺序编号，文献较多时根据窗口大小扩展为双列或三列，再多则滚动显示。点击或按回车阅读后，列表收起，当前文献立即在顶部横向显示，其余文献继续保留在列表中。悬停使用高透明度的分组颜色。列表支持关闭、右键、拖动和方向键导航。拖动到折叠组上停留片刻始终自动展开，不再提供开关。设置页中的简短补充说明可通过悬停查看。

## 一键保存阅读现场

在设置页的「阅读现场」区域，点击 **保存当前阅读现场**。也可使用「工具 → Tab Manager → 保存当前阅读现场」。

保存内容包括当前打开的文献、文献与分组的顺序、分组名称和颜色、备注、显示方式、折叠状态，以及当前阅读的文献。同一篇文献只保存一份。

- 保存操作会替换上一次手动保存的现场。
- 关闭文献不会覆盖保存记录。
- 没有打开文献时，保存操作会保留上一次记录。
- 记录保存在本机 Zotero 配置中，重启后仍可恢复，不随文献库同步。

## 一键恢复阅读现场

点击 **恢复阅读现场**，或使用「工具 → Tab Manager → 恢复阅读现场」。

插件会重新打开已关闭的文献、恢复其分组和阅读顺序，并重建不存在的分组。已经打开的文献不会重复打开，你后来打开的其他文献也会保留。保存时已有的组会恢复保存时的名称、颜色、显示方式和折叠状态，其他分组会保留。

批量恢复使用 Zotero 原生的按需加载标签：先恢复所有可用标签，切换到文献时再加载 PDF。恢复计数以实际创建的标签为准。

阅读现场恢复是手动操作，因此即使关闭了“重新打开文献时恢复原分组”，仍可恢复完整现场。若某篇文献或附件已被删除、无法找到或打开失败，会显示统计，其他可恢复的文献仍会继续打开；可以稍后重试。

阅读现场保存的是文献引用与布局，不复制 PDF 或其他附件，也不能恢复已删除的文献内容。

遇到失败时，设置页会列出具体文献和原因。文件不在本机的附件需要先下载或重新定位，再点击恢复重试。0.6.2 可以继续使用以前保存的现场，无需重新保存。
