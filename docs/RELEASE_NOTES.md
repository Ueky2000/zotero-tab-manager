## Tab Manager 0.5.2

- 未分组默认放在所有命名分组之后，避免大量未分组文献把已整理的分组挤到后方。升级时调整一次，保留其他分组的相对顺序，之后仍可拖动组名调整并保存。
- 分组标题宽度根据名称设置，不再随文献数量增加而变宽；数量仍正常显示。
- 修复包括 Zotero 10.0.1 在内的版本中，原生文献库标签被隐藏的问题。保留原有文献库图标、名称与点击行为，将入口固定在左侧。
- 大量标签仍在中间区域横向滚动，右侧下拉菜单、搜索和建议关闭入口保持可见。
- 直接覆盖旧版安装，保留已有分组和备注。

### 安装

下载下方 Assets 中的 **`tab-manager-0.5.2.xpi`**，在 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」中选择它。必要时重启 Zotero。

### 验证范围

本次在 Windows 上使用独立配置与示例文献库，验证 Zotero 6.0.36（42 项）、7.0.32（46 项）和 10.0.8（46 项），共 134 项界面检查；另有现代与旧版代码各 12 项状态回归检查。覆盖大量标签下的文献库入口、返回操作、分组宽度和原有工具栏。

已核对用户反馈的 10.0.1 原生标签结构。该版本的官方下载地址实际返回内部版本为 10.0.8 的安装包，因此 10.0.1 本身尚未实机验证。macOS、Linux 尚未实机验证。完整记录见 [兼容性说明](https://github.com/Ueky2000/zotero-tab-manager/blob/main/docs/COMPATIBILITY.md)。

设计初衷与完整使用说明见 [README](https://github.com/Ueky2000/zotero-tab-manager#readme)。
