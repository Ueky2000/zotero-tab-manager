## Tab Manager 0.6.4

新增可选的关闭分组后自动解散功能，精简设置页。

- 搜索文献和建议关闭按钮改为再次点击即收起；打开其中一个会关闭另一个弹窗。
- 新增“关闭组内所有文献后自动解散分组”开关，默认关闭。
- 开启后，分组右键的一键关闭操作会同时移除已空的自建分组。未分组始终保留，逐篇关闭不触发。
- 关闭未完成或其他窗口仍有组内文献时，保留分组。
- 保留文献、备注和已保存的阅读现场；若开启重新打开时恢复分组，再次打开文献仍可自动重建原组。
- 移除设置页中的“未分组颜色”，仍可从未分组的右键菜单调整颜色。

完整验证记录见 [兼容性说明](https://github.com/Ueky2000/zotero-tab-manager/blob/main/docs/COMPATIBILITY.md)。

下载 **tab-manager-0.6.4.xpi** 覆盖安装。设置位于 Zotero 设置中的 **Tab Manager**；Zotero 6 使用插件管理器中的「选项 / 首选项」。
