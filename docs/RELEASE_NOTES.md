## Tab Manager 0.5.1

- 修复大量文献标签把原生下拉列表、搜索和“建议关闭”按钮挤出窗口的问题，右侧工具栏保持可见。
- 文献标签在可用区域内横向滚动，支持鼠标滚轮；切换到溢出标签时自动滚入可见区域。
- 修复 Zotero 6 的右侧按钮容器布局。同一安装包支持 Zotero 6–10。
- 直接覆盖旧版安装，保留已有分组和备注。

### 安装

下载下方 Assets 中的 **`tab-manager-0.5.1.xpi`**，在 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」中选择它。必要时重启 Zotero。

### 验证范围

Windows 上已验证 Zotero 6.0.36、7.0.32、8.0.4、9.0.6、10.0.8，共 186 项安装、功能及标签溢出检查；Zotero 7.0.32 另通过 130 项回归检查。溢出测试覆盖 60 个额外标签与 960/1280/1920px 三种宽度。macOS、Linux 尚未实机验证。

设计初衷与完整使用说明见 [README](https://github.com/Ueky2000/zotero-tab-manager#readme)。
