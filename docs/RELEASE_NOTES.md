## Tab Manager 0.6.2

修复“阅读现场”批量恢复不完整、恢复数量不可靠的问题，重点针对 Zotero 7。

- 改用 Zotero 原生会话恢复方式：先还原全部可用标签，切换时再加载 PDF。
- 恢复数量以实际创建的标签为准，避免误报成功。
- 保留已打开的文献及后来打开的其他文献，不重复创建。
- 失败时显示具体文献和原因，其他文献继续恢复。
- 以前保存的阅读现场仍可直接使用，无需重新保存。

已在 Zotero 7.0.32 和 10.0.8 中验证 20 篇真实 PDF 的保存、全部关闭、恢复及逐篇加载；Zotero 6.0.36 验证原生标签恢复与错误处理。完整记录见 [兼容性说明](https://github.com/Ueky2000/zotero-tab-manager/blob/main/docs/COMPATIBILITY.md)。

下载 **tab-manager-0.6.2.xpi** 覆盖安装，然后直接点击“恢复阅读现场”。
