## Tab Manager 1.0.0

首个正式版，支持 **Zotero 7–10**。

- 移除 Zotero 6 专用运行模块、旧安装声明、独立设置窗口和转译构建流程，统一使用 Zotero 7–10 原生插件接口。
- 保留分组、颜色、折叠、备注、搜索、多列文献列表、建议关闭和阅读现场功能。
- 插件 ID 与本地数据格式保持不变，覆盖安装可继续使用原有分组、设置和阅读现场。
- 安装与更新范围调整为 Zotero 7–10，不向 Zotero 6 推荐安装 1.0.0。

**Zotero 6 用户请下载 [0.6.6](https://github.com/Ueky2000/zotero-tab-manager/releases/tag/v0.6.6)。为减少维护成本，本插件后续不再对 Zotero 6 进行更新维护。** 历史版本仍可下载。

完整验证记录见 [兼容性说明](https://github.com/Ueky2000/zotero-tab-manager/blob/main/docs/COMPATIBILITY.md)。

Zotero 7–10 用户下载 **tab-manager-1.0.0.xpi** 覆盖安装。设置位于 Zotero 设置中的 **Tab Manager**。
