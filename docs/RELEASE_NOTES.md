## Tab Manager 0.6.0

- **插件设置**：集中调整分组数量、拖动悬停展开、未分组颜色、默认标签显示及“建议关闭”的显示和天数。修改后立即生效。
- **可选的分组记忆**：开启“重新打开文献时恢复原分组”后，关闭再打开仍归入原组，原组不存在则重建。关闭此选项不会移动当前打开的文献。
- **一键保存阅读现场**：记住所有打开的文献、分组、顺序、颜色、备注、显示方式、折叠状态和当前文献。即使误关全部标签，也能一键恢复；已打开的文献不会重复打开，后来打开的文献会保留。
- **移组后自动定位**：将正在阅读的文献移入另一组后，自动展开目标组并将该文献标签滚动到可见位置。

### 从哪里使用

Zotero 7–10：设置 → **Tab Manager**。Zotero 6：工具 → **Tab Manager → 设置**。

保存和恢复现场也可直接使用「工具 → Tab Manager」菜单。现场保存在本机；再次手动保存会替换上一次记录，关闭标签不会覆盖它。已删除或无法打开的文献会显示统计，其他文献继续恢复。

下载下方 Assets 中的 **`tab-manager-0.6.0.xpi`**，在 Zotero 中从文件安装插件，覆盖旧版即可。

完整操作说明见 [设置与阅读现场](https://github.com/Ueky2000/zotero-tab-manager/blob/main/docs/SETTINGS.md)，验证范围见 [兼容性记录](https://github.com/Ueky2000/zotero-tab-manager/blob/main/docs/COMPATIBILITY.md)。
