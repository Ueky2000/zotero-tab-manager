## Tab Manager 0.6.5

新增未分组重命名开关与设置底部项目信息。

- 新增“是否允许未分组重命名”开关，默认关闭。开启后，未分组右键菜单才显示重命名选项。
- 自定义名称立即生效并在重启后保留；关闭开关只隐藏入口，不重置名称，不改变文献归属。
- 新保存的阅读现场包含未分组名称，旧版阅读现场仍可恢复。
- 设置最底部独立显示当前插件版本、项目网站、小红书反馈帖子及邮箱链接。

完整验证记录见 [兼容性说明](https://github.com/Ueky2000/zotero-tab-manager/blob/main/docs/COMPATIBILITY.md)。

下载 **tab-manager-0.6.5.xpi** 覆盖安装。设置位于 Zotero 设置中的 **Tab Manager**；Zotero 6 使用插件管理器中的「选项 / 首选项」。
