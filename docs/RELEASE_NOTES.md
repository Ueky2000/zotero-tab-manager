## Tab Manager 0.6.6

修正关闭未分组重命名开关后的名称恢复行为。

- 选择“否”后，立即隐藏右键重命名选项，并将名称恢复为“未分组”。
- 开关关闭时，重启或恢复旧阅读现场也不会重新显示自定义名称。
- 选择“是”后仍可重新命名；文献归属和已保存的阅读现场保持不变。

完整验证记录见 [兼容性说明](https://github.com/Ueky2000/zotero-tab-manager/blob/main/docs/COMPATIBILITY.md)。

下载 **tab-manager-0.6.6.xpi** 覆盖安装。设置位于 Zotero 设置中的 **Tab Manager**；Zotero 6 使用插件管理器中的「选项 / 首选项」。
