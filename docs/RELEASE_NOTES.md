## Tab Manager 0.6.3

优化竖向列表、标签显示和设置交互。

- 竖向列表增加编号，按窗口大小自动扩展为双列或三列，超出容量后滚动显示。
- 点击竖向文献后，当前文献立即横向显示在顶部，方便关闭、右键和拖动。
- 新增“分组数量超过此值时全部竖向排列”设置，默认 7；当前阅读的文献保持横向显示。
- 列表悬停使用高透明度的分组颜色。
- 修改默认显示方式后，立即同步到当前所有分组和已打开文献。
- 工具菜单仅保留保存、恢复阅读现场；菜单和设置页按钮使用统一彩色图标。
- 移除“建议关闭”菜单的设置入口，精简设置文案；拖动悬停始终自动展开。

完整验证记录见 [兼容性说明](https://github.com/Ueky2000/zotero-tab-manager/blob/main/docs/COMPATIBILITY.md)。

下载 **tab-manager-0.6.3.xpi** 覆盖安装。设置位于 Zotero 设置中的 **Tab Manager**；Zotero 6 使用插件管理器中的「选项 / 首选项」。
