## Tab Manager 0.6.1

- 修复选中文献标签出现突兀蓝色外框的问题。
- 鼠标点击、拖动和移组后的自动定位不再额外显示焦点框，当前文献保留所属分组颜色与底部色条。
- 键盘操作的焦点提示沿用分组颜色，兼容 Zotero 6 的旧版焦点选择器。
- 精简设置页：颜色、显示方式与天数控件紧跟名称；缩短选项文案，去掉大段解释，次要说明改为悬停提示。
- 分组内文献超过 **7 篇**时，点击组名会在下方弹出竖向列表，顶部仍保持一行；可在设置的“超过此数量时竖向展开”中调整。未分组同样适用。
- 竖向列表支持切换、关闭、右键和拖动；将当前文献移入大分组时，也会展开列表并定位到它。
- 改善文献加载过程中才获得标识时的自动归组。
- 保留拖动加入分组时的提示，以及 0.6.0 的设置、分组记忆和阅读现场功能。

下载 Assets 中的 **tab-manager-0.6.1.xpi**，覆盖安装即可。已有分组、备注、设置和保存的阅读现场会保留。

详细验证范围见 [兼容性记录](https://github.com/Ueky2000/zotero-tab-manager/blob/main/docs/COMPATIBILITY.md)。
